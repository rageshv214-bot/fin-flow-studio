# FIN-FLOW — Student Budget & Expense Visualizer

A dark-themed, 60 FPS animated desktop GUI built in pure Python (`tkinter`) for tracking day-to-day student expenses across Food, Travel, Tech, and Gaming.

## Features
- Real-time animated budget ring and category bar charts (60 FPS)
- 1-click category pills (`Food`, `Travel`, `Tech`, `Gaming`)
- Inline custom expense entry with instant visual updates
- Zero external dependencies (Python standard library only)

## Run Locally
```bash
python3 fin_flow_studio_ui.py
